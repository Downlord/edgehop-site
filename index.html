EdgeHop

One keyboard and mouse for several PCs. Nothing to install on the others.

Move the pointer past the edge of your screen and it continues on the PC next to it. That PC only sees a USB keyboard and mouse, so it works on machines where you cannot install software.

Source on GitHub Getting started

Status: early prototype. Firmware and the Windows app build and the switching logic is unit-tested. Testing on real hardware has only just begun. There are no downloads yet; you build it yourself.

How it works

A small app on your main PC watches the keyboard and mouse. When the pointer leaves the screen towards another PC, the app sends your input to a dongle, which passes it by radio to the dongle plugged into that PC. The dongles talk to each other directly; they do not join your WiFi network.

What it does

No software on the other PCs

Each one gets a dongle that acts as a standard USB keyboard and mouse. No drivers, no admin rights.

Arrange screens by dragging

Place each PC's screen next to yours in the layout editor. The pointer crosses where the screens touch.

Lands where it crossed

The pointer is sent as an absolute position, so it arrives at the right height whatever the other PC's mouse settings are.

Private link

Dongles are paired over USB and only talk to their partner. The link is encrypted and every packet is authenticated.

No stuck keys

If the link drops, the other PC's dongle releases every key and button within half a second.

Type your clipboard

Send clipboard text to the other PC as keystrokes. German and US keyboard layouts are supported.

Media and extra mouse keys

Volume, play/pause, back/forward buttons and horizontal scrolling are passed along.

Keep the others awake

Optionally nudge the pointer on the other PCs while you are at your desk, driven by a Home Assistant occupancy sensor.

Getting started

You need:

  • One ESP32-S3 board with a native USB port for each PC you want to control.
  • One more board for your main PC. This one can be an ESP32-S3 or an ESP32-C6.
  • A main PC running Windows 10 or 11. The other PCs run Windows too for now.
  1. Build the firmware with PlatformIO and flash it to every board.
  2. Build and start the EdgeHop app on your main PC (.NET 8).
  3. Plug in the board for the main PC and choose "Set up master dongle".
  4. Plug in each other board in turn, pair it, then move it to its PC.
  5. Drag the screens into place in the layout editor.

The README has the exact commands.

Limits

  • The other PCs are assumed to have one monitor each.
  • Clipboard goes one way, as typed text. No files or images.
  • At most six other PCs per main PC.
  • Range is about one room.
  • A sleeping PC can only be woken if USB wake is enabled for the dongle on it.
